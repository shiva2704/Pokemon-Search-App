# Pokémon Search App

## Description
The Pokémon Search App allows users to search for Pokémon by name or ID and retrieve detailed information, including their stats, abilities, and images. It provides an interactive and visually appealing way to explore Pokémon data.

## Features
- Search Pokémon by name or ID
- Display Pokémon stats, abilities, and types
- Show Pokémon images and descriptions
- Responsive UI for a seamless experience across devices
- Fetch data from the Pokémon API (PokéAPI)

## Technologies Used
- HTML
- CSS (Bootstrap for styling)
- JavaScript (Fetch API for data retrieval)
- Angular (if applicable)

## Installation & Setup
1. Clone the repository:
   ```sh
   git clone https://github.com/shiva2704/Pokemon-Search-App.git
   ```
2. Navigate to the project folder:
   ```sh
   cd Pokemon-Search-App
   ```
3. Open `index.html` in a web browser or run the app using a local web server.

## Usage
1. Enter a Pokémon name or ID in the search bar.
2. Click the search button to fetch and display the Pokémon details.
3. View stats, abilities, and images of the searched Pokémon.
